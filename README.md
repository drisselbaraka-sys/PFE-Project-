## 🛠️ Stack Technique
- **Frontend** : [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/) + [Tailwind CSS](https://tailwindcss.com/)
- **Backend** : [FastAPI](https://fastapi.tiangolo.com/) (Python)
- **Base de données** : [PostgreSQL](https://www.postgresql.org/)
- **IA** : [Hugging Face](https://huggingface.co/) (Token sécurisé)

## 📦 Structure du Projet
- `/Frontend` : Code source de l'interface utilisateur.
- `/Backend` : API et logique serveur, gestion de la base de données.

## ⚙️ Installation et Configuration

### 1. Cloner le projet
```bash
git clone https://github.com/drisselbaraka-sys/PFE-Project-.git
cd PFE-Project-
```

### 2. Backend
1. Allez dans le dossier Backend : `cd Backend`
2. Créez un environnement virtuel : `python -m venv venv`
3. Installez les dépendances : `pip install -r requirements.txt`
4. **Important** : Copiez `.env.example` vers `.env` et remplissez vos identifiants.

### 3. Frontend
1. Allez dans le dossier Frontend : `cd ../Frontend`
2. Installez les paquets : `npm install`
3. Lancez l'application : `npm run dev`

## 🔒 Sécurité
Les variables d'environnement confidentielles (clés API, mots de passe) sont protégées via `.gitignore` et ne sont pas présentes sur ce dépôt public.
